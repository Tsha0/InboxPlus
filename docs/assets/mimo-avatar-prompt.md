# Mimo avatar

Generated with the built-in imagegen tool. The generated alpha channel is preserved in
`mimo-mascot.png` and `Sources/MimoUI/Resources/MimoMascot.png`. The app icon generator
places the avatar on a cream plate and makes a tighter crop for small icon sizes.

## Final prompt

Use case: logo-brand
Asset type: Mimo messaging app mascot, GitHub README avatar and macOS app icon source.
Primary request: Redesign the referenced blue puppy mascot for the renamed project Mimo. Make a distinctive, polished, simpler face-focused avatar: rounded blue puppy head with soft floppy ears, cream muzzle, friendly dark eyes and a small cheerful smile. Keep the existing blue and cream palette, but simplify the fur into softly sculpted plush forms with minimal texture for clear recognition at small sizes. No body or satchel. Center the complete head and both ears on a flat warm cream square background, with generous even breathing room. Subtle dimensional shading, clean silhouette, welcoming and calm. No text, letters, border, extra objects or watermark.
Input image: reference for the former mascot and palette, not a preservation target.
