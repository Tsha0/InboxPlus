# Pallo Mascot Design

## Goal

Create a friendly mascot named Pallo for the project README. The mascot should make the local-first universal messaging inbox feel warm and approachable without obscuring the README's technical purpose.

## Character

Pallo is a small, round blue puppy. The character has floppy ears, a cream-colored muzzle, bright curious eyes, and a tiny messenger pouch. The puppy should feel loyal, cheerful, and dependable, reinforcing the idea of one friendly companion that keeps conversations together.

## Visual Direction

- Polished, cute 3D-style illustration with soft shapes and tactile detail
- Blue-led palette that complements the app's system-blue interface
- Pale, uncluttered background with the character centered in a square composition
- Readable at both README hero size and small thumbnail size
- No words, logos, border, or watermark inside the artwork
- One character only, with no extra props beyond the messenger pouch

## Repository Integration

Save the final PNG at `docs/assets/pallo-mascot.png`. Add it immediately below the `# Pallo` heading in `README.md`, centered with HTML and displayed at a restrained width so the introduction remains visible without excessive scrolling. Include concise alt text describing Pallo as the app mascot.

## Acceptance Criteria

- The image clearly depicts the approved blue puppy character and messenger pouch.
- The generated asset is stored inside the repository at the documented path.
- The README renders the mascot near its top using a repository-relative reference.
- Existing README content remains otherwise unchanged.
- The image has no accidental text, duplicated anatomy, stray objects, or watermark.
