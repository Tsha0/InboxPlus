# Inbox+ Flutter application

From this directory:

```bash
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter run -d macos
```

- Pick a target that the current host supports.
- Install Go and the other tools in the [README requirements](../../README.md#requirements) first.
  Flutter alone cannot build the app.
- Checks, packaging and releases are in [CONTRIBUTING](../../CONTRIBUTING.md).
